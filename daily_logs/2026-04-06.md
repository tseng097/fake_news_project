## 1) New paper scan (2–3, in-scope)

> Web note: automated web search endpoint was unusable today (bot challenge). I proceeded with best-available, verifiable canonical sources.

### Paper A
- **Citation:** Li, J., Ji, S., Du, T., Li, B., & Wang, T. (2018). *TextBugger: Generating Adversarial Text Against Real-world Applications*. NDSS 2019 / arXiv:1812.05271.
- **Link:** https://arxiv.org/abs/1812.05271
- **Core method:** Black-box and white-box lexical perturbations (character/word-level) targeting high-impact tokens while preserving readability and semantics.
- **Assumptions:** Utility-preserving lexical perturbations can still induce classifier failures; token saliency approximations identify vulnerable anchors.
- **Strengths:** Practical, realistic attack patterns that map well to fake-news text pipelines.
- **Limitations:** Not fake-news-specific; some perturbations are typo-centric vs controlled paraphrase.
- **Worth-Reading (this project):** **84/100**

### Paper B
- **Citation:** Ren, S., Deng, Y., He, K., & Che, W. (2019). *Generating Natural Language Adversarial Examples through Probability Weighted Word Saliency (PWWS)*. ACL 2019 / arXiv:1909.04326.
- **Link:** https://arxiv.org/abs/1909.04326
- **Core method:** Uses probability-weighted saliency to prioritize word substitutions and improve attack success under semantic constraints.
- **Assumptions:** Saliency-guided lexical edits better expose model brittleness than random substitution.
- **Strengths:** Efficient, interpretable token-priority framework; directly useful for robustness-aware lexical augmentation design.
- **Limitations:** General text classification setup; saliency estimates can be model-dependent.
- **Worth-Reading (this project):** **88/100**

### Paper C
- **Citation:** Gao, J., Lanchantin, J., Soffa, M. L., & Qi, Y. (2018). *Black-box Generation of Adversarial Text Sequences to Evade Deep Learning Classifiers*. IEEE Security and Privacy Workshops 2018 / arXiv:1801.04354.
- **Link:** https://arxiv.org/abs/1801.04354
- **Core method:** DeepWordBug framework with black-box token-level edit operations based on scoring heuristics.
- **Assumptions:** Lightweight black-box token importance scores can identify vulnerable lexical anchors.
- **Strengths:** Strong lexical robustness baseline; highlights vulnerability to tiny local edits.
- **Limitations:** Older architecture context and often noisier edit patterns than modern constrained attacks.
- **Worth-Reading (this project):** **79/100**

## 2) Concise synthesis vs current fake_news_project methods
- These papers converge on one key point: **lexical attacks prioritize salient claim-bearing tokens**, not only random words.
- Current `lexical_mhc_lite` already enforces semantic safeguards (entity/quantity/pivot protection + similarity floor), which aligns with preserving label semantics during augmentation.
- A gap they highlight for fake-news robustness is claim-stance drift from edits to **reporting/attribution verbs** (e.g., confirmed/alleged/denied). This can quietly change veracity framing.
- Therefore, today’s update tightens mHC-lite lexical safety by protecting stance-critical reporting verbs while keeping other lexical diversity intact.

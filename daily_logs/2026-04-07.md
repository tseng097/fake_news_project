## 1) New paper scan (2–3, in-scope)

> Web note: the available web search path returned an anti-bot challenge today, so I proceeded with best-available canonical sources.

### Paper A
- **Citation:** Ribeiro, M. T., Singh, S., & Guestrin, C. (2018). *Semantically Equivalent Adversarial Rules for Debugging NLP Models*. ACL 2018.
- **Link:** https://aclanthology.org/P18-1017/
- **Core method:** Generates label-preserving adversarial examples using human-interpretable transformation rules (lexical/discourse edits) to expose model brittleness.
- **Assumptions:** Many small text rewrites are semantically equivalent for task labels; failures under these rewrites indicate shortcut reliance.
- **Strengths:** Directly useful for controlled, interpretable robustness checks; aligns with mHC-lite’s semantic-preservation intent.
- **Limitations:** Rule coverage may be incomplete; transfer from generic NLP tasks to fake-news corpora still needs task-specific validation.
- **Worth-Reading (this project):** **89/100**

### Paper B
- **Citation:** Pruthi, D., Dhingra, B., & Lipton, Z. C. (2019). *Combating Adversarial Misspellings with Robust Word Recognition*. ACL 2019.
- **Link:** https://aclanthology.org/P19-1561/
- **Core method:** Shows text classifiers are highly vulnerable to character-level perturbations and improves robustness via word-recognition style normalization/training.
- **Assumptions:** Misspellings/character noise preserve user intent and label semantics but can trigger disproportionate model errors.
- **Strengths:** Practical and lightweight robustness signal for lexical attack surfaces; strong motivation for conservative lexical perturbation controls.
- **Limitations:** Focuses on character noise more than proposition-level style/sentiment manipulations.
- **Worth-Reading (this project):** **82/100**

### Paper C
- **Citation:** Ribeiro, M. T., Wu, T., Guestrin, C., & Singh, S. (2020). *Beyond Accuracy: Behavioral Testing of NLP Models with CheckList*. ACL 2020.
- **Link:** https://aclanthology.org/2020.acl-main.442/
- **Core method:** Behavioral testing framework with capability-focused test templates (including lexical, robustness, and sentiment phenomena) to stress model invariances.
- **Assumptions:** Standard aggregate metrics hide systematic behavioral failures; capability-level tests reveal robustness gaps better.
- **Strengths:** Very actionable for adding tiny, targeted robustness tests around lexical/style/sentiment invariance.
- **Limitations:** Primarily an evaluation framework, not a direct training method.
- **Worth-Reading (this project):** **86/100**

## 2) Concise synthesis vs current fake_news_project methods

# Daily Log — 2026-04-13

## 1) New papers (strict scope: fake-news robustness + adversarial NLP)

### Paper A — Style robustness via LLM style attacks
- **Citation:** Park, S. et al. (2025). *Adversarial Style Augmentation via Large Language Model for Robust Fake News Detection*. WWW 2025 (arXiv:2406.11260).
- **Link:** https://arxiv.org/abs/2406.11260
- **Core method:** LLM-generated diverse style-conversion attack prompts (AdStyle) for adversarial augmentation during detector training.
- **Assumptions:** Style edits preserve underlying claim/veracity labels; generated rewrites are coherent enough to stress detector shortcuts.
- **Strengths:** Directly targets style vulnerability; practical augmentation pipeline; strong robustness framing.
- **Limitations:** Label-preservation can fail for aggressive rewrites; LLM generation quality/cost dependency.
- **Worth-Reading (this project):** **90/100**

### Paper B — Publisher-style aware adversarial verification
- **Citation:** *Style-News: Incorporating Stylized News Generation and Adversarial Verification for Neural Fake News Detection*. EACL 2024 Long Paper.
- **Link:** https://aclanthology.org/2024.eacl-long.92/
- **Core method:** Style-aware fake-news generation conditioned on publisher metadata, with discriminators for style/source robustness.
- **Assumptions:** Publisher style is a meaningful attack/defense axis; source/style discriminators improve robustness.
- **Strengths:** Explicit threat model for stylized attacks; strong style/source invariance motivation.
- **Limitations:** Requires publisher-style metadata; may transfer less to pure-article datasets with weak source signals.
- **Worth-Reading (this project):** **86/100**

### Paper C — Sentiment adversarial robustness
- **Citation:** Tahmasebi, S. et al. (2026). *Robust Fake News Detection using Large Language Models under Adversarial Sentiment Attacks* (AdSent). arXiv:2601.15277.
- **Link:** https://arxiv.org/abs/2601.15277
- **Core method:** Controlled LLM sentiment attacks + sentiment-agnostic consistency training.
- **Assumptions:** Veracity should be invariant under sentiment rewrites; sentiment is a major spurious cue.
- **Strengths:** Very aligned with sentiment_invariance strategy; clear robustness objective and diagnostics.
- **Limitations:** Dependence on quality/control of sentiment rewriting; potential content drift in generated attacks.
- **Worth-Reading (this project):** **93/100**

## 2) Synthesis vs current fake_news_project methods
- Current project already has the right locked strategy axes (`lexical_mhc_lite`, `style_invariance`, `sentiment_invariance`).
- Relative to AdStyle/Style-News, current style path is lightweight normalization (no external LLM attack generation), so it is efficient but less diverse in style adversaries.
- Relative to AdSent, current sentiment path already uses controlled phrase/token sentiment perturbations and consistency loss; this is conceptually aligned.
- Lexical path (mHC-lite) is where accidental semantic drift risk remains highest; strengthening lexical semantic/grammatical preservation is high-value and low-scope.

## 3) Code enhancement implemented today (small, testable, scope-locked)

### Enhancement
Added **POS-consistency filtering** in `lexical_synonym_perturb` (mHC-lite line): candidate synonyms are now accepted only when replacement has matching WordNet POS (when POS metadata is available).

### Why (paper-grounded)
Adversarial lexical papers and fake-news robustness work repeatedly show context-free word substitutions can introduce grammar/meaning drift. Same-POS filtering is a lightweight guardrail that keeps lexical perturbation closer to paraphrastic invariance.
